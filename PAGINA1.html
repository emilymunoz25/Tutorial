arquitectura web

relacion entre cliente, servidor y tecnologias modernas

devsite

modelo cliente - servidor

es la base de la web: el cliente (navegador) realiza solicitudes y el servidor responde con datos o paginas.

frontend

parte visual que interactua con el usuario. se ejecuta en el navegador.

  • html - estructura
  • css - estilos
  • javascript - logica

backend

procesa datos, maneja servidores y conecta con bases de datos.

  1. node.js
  2. python
  3. php

apis

permiten la comunicacion entre frontend y backend mediante peticiones http.

tecnologias web

area tecnologias
frontend react, angular, vue
backend node.js, django, laravel
base de datos mysql, mongodb

protocolo http

permite la comunicacion en la web mediante metodos como get, post, put y delete.
