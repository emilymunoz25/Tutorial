Lineas separadas horizontales

Existen dos formas para crear una línea separadora horizontal y una única forma para crear una línea separadora vertical. Para crear una línea horizontal la forma fácil y rápida es utilizar la etiqueta < hr >, que no se cierra y que crea una línea horizontal simple.

En lo referente a los tipos de bordes existen las siguientes posibilidades: none: sin línea. solid: con línea continua (valor por defecto). dotted: línea punteada. dashed: línea discontinua (segmentos cortos de línea). inset: línea con el color en bajorelieve. outset: línea que simula el relieve.

Lineas separadas verticales

Para crear líneas verticales tenemos que definir uno de los 4 bordes que tiene una caja (< div >), utilizando una (o varias) de estas propiedades:

Ejemplo

Bordes simples

borde simple


width: 300px;
height: 100px;
border: 3px solid blue;
border-radius: 22px;
padding-left: 15px;
padding-top: 30px;

Bordes redondeados

Con la propiedad border-radius tenemos la posibilidad de crear < div > con las esquinas con bordes redondeados, pudiendo especificar la suavidad de las esquinas de manera conjunta o cada una de las esquinas por separado. Para poder visualizar una esquina con borde redondeado, además de la propiedad border-radius, tenemos que definir un borde normal (con border) y/o indicar un color de fondo (con background-color).

Ejemplo de bordes diferentes
border-radius: 10px 0px 39px 22px;
