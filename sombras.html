Sombras de < div > (cajas)

Ejemplo

Con HTML5 podemos crear de una manera sencilla tanto sombras para zonas del HTML (< div >, < article >, < footer >, < header >...), como para textos. Aunque cada uno de estos tipos de sombra tiene su propia etiqueta, la sintaxis sigue la misma lógica. Así, en el caso de la sombra aplicada a < div >, zonas o secciones del html utilizamos la propiedad box-shadow.

Sombras internas

Para crear sombras internas únicamente tenemos que añadir el valor inset al final de 'box-shadow':

Sombra interna
  • (7px), indica el número de pixeles que se desviará la sombra horizontalmente.
  • (20px), especofoca el número de píxeles que se moverá la sombra verticalmente.
  • (10px), es la suavidad que tendrá la sombra (a menor valor más duro será el borde)
  • color

Creación de 'halos' o 'resplandores'

Para crear un halo o resplandor que rodee una caja o el < div > que corresponda indicamos '0px' en los dos primeros valores y especificamos el color del resplandor.

Ejemplo

section{ box-shadow: 0px 0px 30px blue; }
